# Smart File Audit Tool

A smart CLI-based file automation and audit tool built using core Python.

## Features
- Scan directories for files
- Categorize files by type (Images, Documents, Archives, Code, etc.)
- Organize files into structured folders
- Generate audit logs for all operations
- Safe: never modifies original files
